# Eclipse - Difficulty Matrix

**Purpose:** Defines global difficulty behavior for AI, encounter design, and sandbox balance.  
All missions reference this matrix when tuning spawns, AI traits, and resource distribution.

---

| Category | Easy | Normal | Heroic | Legendary |
|-----------|------|---------|---------|------------|
| **Enemy Tiers** | Grunt/Jackal Minors, Blue Elite | Grunt Majors, Red Elite | Elite Ultras, early Brutes, Shield Jackals | Honor Guards, Brute Captains, Elite Commanders |
| **Encounter Density** | 2–3 squads / zone | 3–5 squads | 4–7 squads + flanks | 6–10 squads + reinforcements |
| **Mini-Boss Presence** | Rare / tutorial only | Occasional (1–2 per mission) | Frequent (2–4 per mission) | Regular (1 every major set piece) |
| **Weapon Pools (Enemy)** | Base CE loadouts | + Needlers & Plasma Rifles | + Halo 2 imports, grenades common | + High-tier/custom weapons, dual-type elites |
| **AI Aggression Multiplier** | 0.9× | 1.0× | 1.35× | 1.6× |
| **AI Accuracy Multiplier** | 0.85× | 1.0× | 1.2× | 1.4× |
| **Health/Shield Multiplier** | 0.9× | 1.0× | 1.25× | 1.5× |
| **Reinforcement Delay** | 30–60 s | 20–40 s | 12–25 s | 6–15 s |
| **Flank & Grenade Rate** | Low | Moderate | High | Very High |
| **Checkpoint Density** | Default | Default | Sparse | Rare |
| **Power Weapon Availability** | Generous | Standard | Guarded / scarce | Very limited / high-risk |
| **Marine Survivability** | High | Moderate | * | Low |
| **Narrative / Audio Tone** | Calm, tutorial hints with some cues | Escalation cues | Dire comms chatter | Urgent chatter |
| **Lighting / Visual Tone** | Classic CE palette | Slightly darker | * | Bleak, but familiar |
| **Recommended Player Base** | First-time / story | Baseline Halo fans | Veterans, “true” CE feel | Masochists, challenge runs |

---

### Global Notes
- **AI scaling**: Prefer smarter positioning to extra HP.  
- **Ammo distribution**: Less ammo dropped across the board, demanding careful management of shots.
- **Tone scaling**: Heroic is the *baseline design*; other tiers scale outward from it.
