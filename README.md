# Eclipse

This is a large content mod for Halo: Combat Evolved, built with the tools provided by the MCC. This mod not only introduces a large amount of new content, but also makes changes to existing vanilla content!

Eclipse not only expands on the story and campaign of CE, but also ramps up the difficulty for an additional challenge. Everything has been carefully tuned to make CE a difficult campaign without making it feel unfair to the player.

Documentation on every mission (both custom and vanilla) can be found in the `docs` directory, and this includes layouts, plans, design notes, and a step-by-step on completing each mission. It also contains the designs and pseudocode for a lot of the custom enemies and other interesting things in this mod.

> [!NOTE]
> This mod is **Singleplayer** only, multiplayer is unsupported and there are no plans for it!
